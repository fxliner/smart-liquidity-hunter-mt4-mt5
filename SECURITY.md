# Security policy

## Supported version

The current free MT4/MT5 distribution is v1.11. Older builds may not receive fixes.

## Reporting sensitive findings

Do not publish credentials, tokens, personal data, broker account information or working exploitation instructions in public GitHub Issues.

Use GitHub's private vulnerability reporting feature if the repository offers **Report a vulnerability** under Security. If that feature is unavailable, open a minimal non-sensitive issue asking the maintainer for a private reporting channel; do not include the vulnerability details publicly.

The indicator is not an Expert Advisor and is not intended to place trades. Download only from the documented MQL5 Market, GitHub or SourceForge project pages.
