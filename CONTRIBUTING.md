# Contributing

Contributions to improve compatibility, calculation correctness, documentation, accessibility and reproducible tests are welcome.

1. Check [existing issues](https://github.com/fxliner/smart-liquidity-hunter-mt4-mt5/issues) first.
2. Include the MT4/MT5 build, chart symbol, timeframe, reproducible steps and non-sensitive screenshot.
3. For code changes, explain how pivot confirmation, historical marks, alerts and defaults are affected.
4. Keep the closed-bar signal behavior unless a change is carefully justified and documented.
5. Preserve the [MIT License](LICENSE) and existing contributor attribution.

**Security:** never upload credentials, account numbers, private trading logs or access tokens. Project landing page: [FOREXREVIEW.TOP](https://forexreview.top/).
