For a reproducible report, include the indicator version, MT4/MT5 terminal build, symbol, timeframe, parameters and an anonymized screenshot. Never provide passwords, account numbers, private broker credentials or access tokens.

**ZIP extraction:** v1.11 was created on Windows and uses Windows-style separators in some archive member names. On systems other than Windows, use an extraction tool that recognizes or normalizes these paths and verify the resulting directory layout. The SHA-256 manifest refers to files *inside* the release ZIP. See the automated [distribution verifier](scripts/verify_distribution.py).

This is an educational chart indicator, **not** an order-execution system or a guarantee of profit.
